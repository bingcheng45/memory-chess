# Third-party mentions

This file is the running list of pages on other sites that name Memory Chess. AI answers lean on these pages: across 75,000 brands, mentions on other sites tracked AI Overview visibility at 0.664, against 0.218 for backlinks (Ahrefs, May 2025, a correlation on larger sites). The monthly check in [README.md](README.md) counts the live rows in the first table, and only those.

## Counting rule

A page counts toward the measure only when all three hold:

1. It is on a host the site owner does not run.
2. The owner did not write it or submit it. A listing the owner filled in, a post the owner made, and a pull request the owner opened all fail this test.
3. It is not an automatic copy of another page, such as a Product Hunt mirror.

A page that passes goes in the first table. A listing the owner submitted goes in the second table, which is tracked but never counted. The owner's own accounts and automatic copies go in the third table. Never delete a row. If a page drops Memory Chess or goes offline, set its status and keep the row.

The status cell in the first two tables holds exactly one of these values:

- **live.** The page names Memory Chess on the day it was last checked.
- **unconfirmed.** The page names Memory Chess, but nobody has confirmed that it passes the counting rule. Only the owner can clear this, by saying whether they submitted the page.
- **removed.** The page loads but no longer names Memory Chess.
- **offline.** The page does not load.

The measure is the count of first-table rows whose status is "live" and whose "Last checked" date is in the current check.
