# Memory Chess brand directions

The homepage currently mixes two designs. This folder holds three candidate brand systems that merge them into one. Use the chosen sheet as the reference for every future page revamp.

Status: no direction chosen yet. When one is picked, record it here and treat the other two sheets as rejected alternatives.

## The two themes on today's homepage

| | v1, original Memory Chess | v2, Brain Lab |
|---|---|---|
| Where | Changelog banner, header, video, FAQ, footer | Everything between the header and the footer |
| Surface | Pure black | Mint paper `#f5f9f8` with a blue 24 px graph grid |
| Accent | Peach on the wordmark and footer links | Ink `#0d1b24`, blue `#1f4fe0`, mint `#3fd0a8`, orange marker `#f2612d` |
| Layout | Centred | Left-aligned, two-column section heads |
| Headings | Title Case ("Questions About Memory Chess") | Sentence case with a full stop ("Take a calibration reading.") |
| Labels | None | Geist Mono capitals ("§03 / FIELD RECORDING") |
| Board | Wood `#f0d9b5` / `#b58863` on /game | Mint squares on the homepage |

The visible seams are two stacked navigation bars, two brand marks, two board palettes, two heading voices, competing peach and orange accents, and a black footer under a light page.

## Rules every direction keeps

- One sticky header with one wordmark. Site links and on-page links merge, and the extra links sit behind a menu on phones.
- Geist for headings, navigation, buttons, labels and figures. Open Sans for paragraphs, FAQ answers, helper text and captions. Geist Mono only for real data: clocks, scores, coordinates, FEN strings.
- One board palette for every board on the site, including /game.
- Section numbers only where the order is real, such as the method phases and calibration steps.
- Board marks never rely on colour alone. Attack, defend, chain and blocked each have their own shape.

## The three directions

- [Lab Paper](lab-paper.md). Light first. The lab sheet becomes the whole brand with one blue accent and a slate board. Peach, black bands and the always-on grid are retired. Includes a designed night theme.
- [Night Study](night-study.md). Dark first. Keeps v1's near-black and peach wordmark, redraws the lab's figures for a dark page, and uses a walnut board. Includes a designed light theme.
- [Ranks and Files](ranks-and-files.md). Alternating night and paper bands. Night bands hold play and brand moments, paper bands hold reading and data, and the board squares are made from the same two colours.

Each sheet lists colour tokens with measured contrast, the type scale, spacing and radius, components, board marks, voice rules, and a do and don't list.
