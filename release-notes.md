## Memory Chess v1.2.1

### Steadier gameplay

- Thanks to helpful player feedback, the board now stays in the same place when memorization ends and placement begins. The controls and piece picker line up with the board too.
- Page headers, sound controls, and spacing now stay more consistent as you move through the game. Board pieces and labels can no longer be selected by accident.

### Better random positions

- Thanks to a player who reported this on Reddit, random positions no longer place kings beside each other, two bishops for one side on the same square color, pawns on the first or eighth rank, or both kings in check.

### Clearer results

- Results now compare the position you memorized with the board you submitted, with clear markers for correct, incorrect, and missed pieces.
- Accuracy, replay, and leaderboard actions now stay together at the top. Missed pieces use a black dotted outline while the board remains visible underneath.

### A clearer finish

- When you submit, the timer stops for one second so you can see your locked-in time and final board before the results appear. A quick GAME! flash marks the end of the round, and the placement timer now shows milliseconds.

## Memory Chess v1.2.0

### Learn and improve

- Added a Learning Center with practical, research-informed guides for chess memory and visualization
- Refreshed the homepage with a clearer spatial-memory training loop and improved board preview

### Everyday improvements

- Made mobile chess-board interactions more dependable
- Corrected generated piece limits to better reflect a standard chess set
- Refined leaderboard ordering for fairer score comparisons
- Improved site metadata, navigation, and application stability
- Lowered the default sound volume from 100% to 10% while preserving the full desktop volume control

### Feedback and updates

- Added an in-app changelog and dismissible update banner for future releases
- Added anonymous result-screen feedback with a 24-hour cooldown between prompts
- Added a clear privacy policy for browser storage, analytics, feedback, and advertising
